# PowerHub — неофіційний Android-клієнт для станцій EcoFlow

Моніторинг і керування зарядними станціями EcoFlow з одного екрана: заряд, мережа, сповіщення про відключення світла, графіки.

**Поточна версія: 0.6.0** · [Завантажити APK](../../releases/latest) · [Свіжа dev-збірка](../../releases/tag/dev)

## Підтримувані моделі

| Модель | Префікс SN | Протокол |
|---|---|---|
| Delta 2 | `R331` | JSON |
| Delta 2 Max | `R351` | JSON |
| Delta Max | `DA` | JSON (команди `TCP`) |
| River 2 Max | `R611` | JSON |
| Delta 3 / Delta 3 Max | `P231` | protobuf |
| Delta Pro 3 | `MR51` | protobuf (телеметрія) + JSON (команди) |

## Можливості
- **Вхід** з обліковим записом EcoFlow (той самий, що в офіційному застосунку). Пароль зберігається зашифрованим лише на телефоні.
- **Список станцій з акаунта:** з ключами [EcoFlow Developer](https://developer.ecoflow.com) станції підтягуються автоматично, з назвами й моделями, однаково на всіх телефонах. Без ключів станції додаються вручну за серійним номером.
- **Моніторинг у реальному часі** через MQTT: заряд, вхід і вихід, мережа, сонце, AC, DC, USB, час до заряду або розряду, температура, цикли, SOH.
- **Керування:** виходи AC, DC і USB, X-Boost, ліміти заряду й розряду, потужність заряду від мережі, резерв, тайм-аути, звук. Набір залежить від моделі.
- **Сповіщення:** зникло або з'явилося живлення, низький заряд (поріг налаштовується), повний заряд, станція не на зв'язку. Працюють у фоні й після перезавантаження телефона.
- **Графіки** заряду й потужності за 6 год, 24 год, 7 і 30 днів, підсумок енергії та часу без мережі.
- **Головний екран:**
  - компактні картки: вміщається 6+ станцій;
  - анімація заряджання, коли станція на мережі;
  - перетягування карток і сортування «спершу онлайн», за назвою або за зарядом;
  - перейменування й видалення станцій.
- **Віджет** на головний екран і постійне сповіщення зі станом.
- **Темна, світла або системна тема.**
- **Вкладка «Дані»** зі всіма сирими полями від станції для налагодження.

## Встановлення
1. Завантажте APK з [Releases](../../releases/latest) на телефон (Android 8+).
2. Відкрийте файл і дозвольте встановлення з цього джерела.
3. Увійдіть з email і паролем EcoFlow. Якщо вхід не проходить із сервером «Глобальний», спробуйте «Європа».
4. **Налаштування → Список станцій з акаунта:** вставте Access Key і Secret Key з developer.ecoflow.com. Або додайте станції вручну кнопкою «+».
5. Дозвольте сповіщення і вимкніть оптимізацію батареї для PowerHub, щоб сповіщення приходили вчасно.

Оновлення встановлюються поверх, налаштування й історія зберігаються.

## Видалення станції
Видалення в PowerHub прибирає станцію лише зі списку на цьому телефоні. **Акаунт EcoFlow не змінюється:** станція лишається прив'язаною і працює в офіційному застосунку. Станції з акаунта після видалення не повертаються під час синхронізації; відновити їх можна в Налаштуваннях → «Видалені станції».

## Збирання
**Автоматично:** кожен push у `main` збирається через GitHub Actions ([build.yml](.github/workflows/build.yml)), і APK публікується як [Dev build](../../releases/tag/dev). Тег `v*` створює звичайний реліз. APK підписується постійним ключем із секретів `SIGNING_KEYSTORE_B64` і `SIGNING_PASSWORD`.

**Локально:**
1. Встановіть [Android Studio](https://developer.android.com/studio) (Ladybug або новішу).
2. File → Open → оберіть теку `PowerHub`. Studio сама завантажить Gradle 8.11 і залежності.
3. Підключіть телефон з налагодженням по USB і натисніть **Run**.

## Як це працює
- **Вхід:** `POST https://api.ecoflow.com/auth/login` повертає токен, а `GET /iot-auth/app/certification` — облікові дані MQTT.
- **Список станцій:** `GET /iot-open/sign/device/list` офіційного Developer API з підписом HMAC-SHA256.
- **MQTT** (TLS, адресу брокера повертає сервер):
  - телеметрія: `/app/device/property/{SN}`
  - команди: `/app/{userId}/{SN}/thing/property/set` (+ `set_reply`)
  - повний знімок стану: `/app/{userId}/{SN}/thing/property/get` (+ `get_reply`)

Протокол і proto-схеми взято з відкритого проєкту [tolwi/hassio-ecoflow-cloud](https://github.com/tolwi/hassio-ecoflow-cloud) (Apache-2.0).

## Структура
```
app/src/main/
  proto/        proto-схеми Delta 3 і Delta Pro 3
  java/app/powerhub/
    api/        EcoflowCloud (вхід), EcoflowOpenApi (список станцій), MqttLink (MQTT)
    protocol/   DeviceModel і протоколи: Delta2, Delta3, DeltaPro3, LegacyJson (Delta Max, River 2 Max)
    data/       Repository, сховища налаштувань і ключів, HistoryDb (SQLite)
    service/    MonitorService (фоновий моніторинг), AlertEngine (сповіщення)
    widget/     віджет (Glance)
    ui/         екрани на Jetpack Compose
```

Щоб додати нову модель, реалізуйте `DeviceProtocol`, додайте її до `DeviceModel` і до `DeviceModel.detect` (префікс SN).

## Історія версій
- **0.6.0:** темна тема за замовчуванням, анімація заряджання, компактніший головний екран.

## Обмеження
- Вхід і MQTT працюють через неофіційний API, тож EcoFlow може змінити його без попередження.
- Команди для Delta 3 Max, Delta Max і River 2 Max взято зі спільноти й ще не перевірено на всіх прошивках. Якщо якийсь показник порожній, подивіться вкладку «Дані».
